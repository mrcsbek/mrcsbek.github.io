Частые вопросы

Нужен ли интернет для работы приложения?

Да. Приложение синхронизируется с вашим личным сервером. Для сохранения новых транзакций и чеков требуется активное подключение к сети.

Есть ли версия для iOS?

На данный момент доступен только Android APK. Однако использование React Native Expo позволяет собрать версию для iOS в будущем.
