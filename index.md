# MoneyApp
Умный учет финансов с автоматическим распознаванием чеков.

[Скачать для Android](#) 

## Ключевые функции
* **Мгновенный ввод данных:** Интеграция CameraX и ML Kit OCR.
* **Продвинутая аналитика:** Настраиваемые финансовые модели (максимум 2 уровня вложенности).
* **Контроль бюджета:** Индивидуальные правила и лимиты.

---

## Техническая документация
* **Платформа:** Android.
* **Фреймворк:** React Native Expo.
* **Распознавание:** CameraX + Google ML Kit OCR.
