# MoneyApp
Умный учет финансов с автоматическим распознаванием чеков. Контроль бюджета, гибкая категоризация и настраиваемые правила без рутинного ручного ввода.

[Скачать для Android](#) 

## Ключевые функции
* **Мгновенный ввод данных:** Интеграция CameraX и ML Kit OCR для точного и быстрого парсинга кассовых чеков.
* **Продвинутая аналитика:** Настраиваемые финансовые модели с глубокой иерархией подкатегорий (максимум 2 уровня вложенности).
* **Контроль бюджета:** Индивидуальные правила и лимиты расходования средств для каждой категории.

---

## Техническая документация

### Архитектура и стек
* **Платформа:** Android.
* **Фреймворк:** React Native Expo.
* **Распознавание:** CameraX + Google ML Kit OCR.

### Схема данных (Базовые модули)
* `Transactions`: Сумма, дата, ID категории, фото чека, текстовый вывод OCR.
* `Categories`: Дерево финансовых категорий.
* `Budgets`: Правила и финансовые лимиты.

## Руководство пользователя

### Сценарий 1: Сканирование чека
1. Нажать иконку камеры на главном экране.
2. Навести фокус на чек, сделать снимок.
3. Дождаться завершения ML OCR-парсинга.
4. Проверить распознанные суммы и категории.
5. Нажать «Сохранить транзакцию».

### Сценарий 2: Настройка лимитов
1. Перейти в раздел бюджетов.
2. Выбрать необходимую категорию.
3. Задать числовой лимит и период действия правила.
